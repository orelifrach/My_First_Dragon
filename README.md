HOW TO PLAY THE GAME
- strat by starting the web - run the web.py file
- enter the starting url - "http://127.0.0.1:5000/start?type=<pet-type>&name=<puppy-name>"
- from the home page you can move to other pages - info and actions by clicking the buttons
- in order to return to the home page from each page - click the arrow "->" on the top of the page
